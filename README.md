# Выпускная квалификационная работа "iOS трекер целей с виртуальным ментором"

Это реализация серверной части клиент-серверсного iOS-приложения 

## Описание

Программа «iOS трекер целей с виртуальным ментором» предназначена для пользователей, которые стремятся эффективно планировать свои долгосрочные цели, структурировать их на этапы и интегрировать задачи в ежедневный график. С помощью LLM приложение выступает в роли виртуального ментора, предлагающего персонализированные рекомендации, корректирующего план действий на основе изменений в целях.

## Основные функции
- Аутентификация пользователей (bcrypt хеширование паролей)
- Управление целями и этапами их выполнения (CRUD операции)
- Интеграция с Large Language Models (переформулировка целей, валидация)
- Генерация расписаний выполнения задач
- Централизованная обработка ошибок (стандартизированный JSON-формат)
- Поддержка CORS для кросc-доменных запросов

## Технологии

Приложение разработано на языке Go. Для организации архитектуры приложения применена 4хслойная архитектура.
